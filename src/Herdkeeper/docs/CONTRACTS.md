# Herdkeeper: Engine-Facing Contracts

Risk: **runtime-sensitive** (server-side writes to saved creature data and creation of new world objects).

Baseline: Valheim **1.0.20** (network version 41, Steam build 25909357), Unity 6000.0.75f1, BepInEx 5.4.23.5, as recorded in `docs/evidence/baseline.json`. Verified on 2026-10-26 against `reference/decompiled/assembly_valheim`. No Harmony patches, RPCs or custom saved fields.

Used BepInEx members: `BepInPlugin(string,string,string)`, `BaseUnityPlugin.Config`/`.Logger`, `ConfigFile.Bind<T>(string,string,T,string)`, `ManualLogSource.LogInfo/LogWarning/LogError(object)`. Status: **Source-verified**.

## Known Differences From Vanilla

- Hunger is ignored for unloaded animals, by design. Loaded animals are untouched and still need food.
- Offspring is placed behind the parent exactly like vanilla, so it can end up on the far side of a fence that the parent faces, as in vanilla.
- No birth or love effects are played.
- An animal in an area that a player enters during a pass can receive one last update in that pass. The player then receives the newer data revision.
